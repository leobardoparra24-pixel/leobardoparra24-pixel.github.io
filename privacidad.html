Estudio Viral — Política de privacidad

Última actualización: 7 de noviembre de 2026

1. Quién la usa

Estudio Viral es una herramienta personal que usa únicamente su propietario (el creador del canal AudioFree) con sus propias cuentas de YouTube, TikTok, Instagram y Facebook.

2. Qué datos se usan

  • Tokens de acceso que el propietario otorga al autorizar cada plataforma (OAuth).
  • Información básica del propio perfil (nombre de usuario e identificador) para confirmar a qué cuenta se sube el video.
  • Los videos, títulos y descripciones que el propietario crea y aprueba.
  • Estadísticas públicas de videos de YouTube (vistas, likes, comentarios) obtenidas con la YouTube Data API para analizar tendencias.

3. Para qué se usan

Exclusivamente para subir los videos del propietario a sus propias cuentas y para analizar tendencias públicas. No se usan para publicidad, perfiles de usuarios ni ningún otro fin.

4. Dónde se guardan

Todo se guarda localmente en la computadora del propietario. No hay servidores propios ni bases de datos externas. Los datos solo se envían a la plataforma correspondiente (Google/YouTube, TikTok o Meta) al momento de publicar.

5. Con quién se comparten

Con nadie. No se venden ni se comparten datos con terceros.

6. Datos de otras personas

La herramienta no recopila datos personales de otros usuarios. Solo lee estadísticas públicas agregadas de videos.

7. Cómo revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde la configuración de seguridad de cada plataforma y borrando los tokens guardados localmente.

8. Uso de datos de Google

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Estudio Viral — Privacy Policy

Last updated: November 7, 2026

1. Who uses it

Estudio Viral is a personal tool used only by its owner (the creator of the AudioFree channel) with the owner's own YouTube, TikTok, Instagram and Facebook accounts.

2. Data used

  • Access tokens the owner grants when authorizing each platform (OAuth).
  • Basic information from the owner's own profile (username and ID) to confirm which account a video is uploaded to.
  • Videos, titles and descriptions the owner creates and approves.
  • Public YouTube video statistics (views, likes, comments) obtained via the YouTube Data API for trend analysis.

3. Purpose

Solely to upload the owner's videos to the owner's own accounts and to analyze public trends. Not used for advertising, user profiling or any other purpose.

4. Storage

Everything is stored locally on the owner's computer. There are no servers or external databases. Data is only sent to the relevant platform (Google/YouTube, TikTok or Meta) at the time of publishing.

5. Sharing

None. Data is never sold or shared with third parties.

6. Other people's data

The tool does not collect personal data about other users. It only reads public, aggregated video statistics.

7. Revoking access

The owner can revoke access at any time from each platform's security settings and by deleting the locally stored tokens.

8. Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
